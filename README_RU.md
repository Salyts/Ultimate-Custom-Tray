# Ultimate Custom Tray 2.1

Этот мод добавляет настраиваемые иконки в системный трей Windows с возможностью назначения действий и контекстных меню, поддержкой файлов изображений и иконок приложений, а также автоматической адаптацией под тему системы.

### [> English documentation <](https://github.com/Salyts/Ultimate-Custom-Tray)

---

## Установка

1. Установите [Windhawk](https://windhawk.net/).
2. Откройте **Windhawk** → **Explore** → **Search**.
3. Введите **Ultimate Custom Tray** в поиске.
4. В результатах выберите [Ultimate Custom Tray](https://windhawk.net/mods/ultimate-custom-tray).
5. Нажмите кнопку "Install".

---

## Быстрый старт

1. Откройте настройки мода в Windhawk.
2. Добавьте один или несколько **элементов (Items)**.
3. Заполните поля **Label**, **Icon** и **Action** для каждого элемента.
4. Сохраните — иконки сразу появятся в трее.

## Форматы действий

| Префикс | Пример | Описание |
|--------|---------|-------------|
| `" "` | `"C:\Program Files\Windhawk\windhawk.exe"` | Открывает файл или папку по пути. |
| `~` | `~Downloads` и `~windhawk.exe` | Открывает папку или файл по имени. |
| `cmd:` | `cmd:control` | Запускает команду через `cmd.exe`. |
| `shell:` | `shell:shutdown /r /f /t 0` | Выполняется через `powershell.exe`. |
| `press:` | `press:Win+E` или `press:0x5B;0x45` | Нажатие клавиш [(Win32 key code)](https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes). |
| `web:` | `web:https://windhawk.net/` | Открывает ссылку в браузере. |
| `ms-settings:` | `ms-settings:bluetooth` | Открывает страницу настроек Windows. |

### Модификаторы (добавляются перед действием)

| Символ | Пример | Описание |
|--------|---------|-------------|
| `-` | `-"C:\Program Files\app.exe"` или `-shell:shutdown /r /f /t 0` | Запуск от имени администратора. |
| `*` | `*cmd:tasklist` или `*shell:Get-Process` | Запуск в окне терминала (только для `cmd:` и `shell:`). |

Можно комбинировать: `-*cmd:tasklist` — админ + с консолью.

## Поле иконки

| Тип | Пример | Описание |
|---|---|---|
| **Глиф** | `E774` | Hex-код символа [Segoe Fluent Icons](https://learn.microsoft.com/en-us/windows/apps/design/iconography/segoe-ui-symbol-font). Только 4 символа, без `\u`. |
| **Файл изображения** | `C:\Icons\name.png` | Путь к изображению. Поддержка: `.png`, `.ico`, `.jpg`, `.bmp`. Рекомендуется 32x32 px с прозрачностью. |
| **Приложение** | `C:\Program Files\Windhawk\windhawk.exe` | Путь к `.exe` или `.dll`, иконка берётся из файла. |

## Настройки стиля

### Цвет иконок (Icon color)

- **Auto** — автоматически подстраивается под тему Windows (светлая/тёмная).
- **White** — всегда белые иконки (для тёмной панели задач).
- **Black** — всегда чёрные иконки (для светлой панели задач).

### Цвет контекстного меню (Context menu color)

- **Auto** — подстраивается под тему Windows.
- **Light** — светлый фон, тёмные иконки.
- **Dark** — тёмный фон, светлые иконки.

---

## Настройки контекстного меню (Open menu near tray icon)

### Открытие рядом с иконкой

Если включено, меню открывается рядом с иконкой, а не под курсором.

### Направление меню (Menu direction)

- **Above icon** — над иконкой  
- **Below icon** — под иконкой  
- **Left of icon** — слева  
- **Right of icon** — справа  

### Выравнивание (Menu alignment)

- **Center** — по центру иконки  
- **Left** — по левому краю  
- **Right** — по правому краю  

### Отступ (Menu offset)

Расстояние между иконкой и меню (0–200 пикселей, по умолчанию 10).

## Элементы трея

Каждый элемент создаёт отдельную иконку в системном трее.

### Настройки элемента

- **Label** — текст при наведении.
- **Icon** — иконка (глиф, файл, exe).
- **Action** — действие при клике.
- **Swap mouse buttons** — меняет местами левую и правую кнопку.
- **Context menu** — меню по правому клику.

### Элементы меню

- **State** — состояние (включено / отключено / скрыто).
- **Name** — название пункта.
- **Description** — описание справа (например, горячая клавиша).
- **Icon** — иконка пункта.
- **Action** — действие при нажатии.
- **Separator** — разделитель (сверху или снизу).
